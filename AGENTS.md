# Codex Extensions

This repository is a Codex plugin marketplace. Keep plugins Codex-native:

- Use `.codex-plugin/plugin.json` for every plugin.
- Prefer skills in `skills/<name>/SKILL.md`.
- Use `.mcp.json` only when the plugin actually exposes MCP servers.
- Keep secrets out of files; use the 1Password `op-secrets` skill patterns.
- Do not add AI attribution to commits, PR text, or generated docs.
